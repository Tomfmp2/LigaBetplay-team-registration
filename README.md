# LigaBetplay Team Registration

## Descripción
Aplicación web para gestionar datos de equipos de la Liga BetPlay. Utiliza **HTML** para la estructura, **CSS** para el diseño visual y **JavaScript** para la funcionalidad dinámica.

## Características
- Registro y gestión de información de equipos.
- Interfaz sencilla y responsiva.
- Funcionalidades dinámicas para interactuar con los datos.

## Tecnologías
- **HTML**: Estructura de la aplicación.
- **CSS**: Estilo y diseño visual.
- **JavaScript**: Lógica y dinamismo.

## Instalación
    1. Clona el repositorio:
        ```bash
        git clone https://github.com/Tomfmp2/LigaBetplay-team-registration.git
    2. Navega al directorio:
        cd LigaBetplay-team-registration

# Uso

Accede a la aplicación desde un navegador.
Usa la interfaz para registrar, editar o consultar datos de equipos.
